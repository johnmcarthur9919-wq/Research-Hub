Uncovering the Instructions Behind AI

Welcome to the AI System Prompt Research Hub. This documentation site exists to collect, analyze, and archive the foundational "system prompts" that guide large language models and agentic platforms.

Why this exists

System prompts dictate AI behavior, safety guardrails, and baseline personas. By documenting these instructions in an open, searchable hub, researchers and developers can better understand how different providers shape their models' reasoning and boundaries.

Contribute to the Archive

This is a community-driven research hub. When submitting a newly discovered or updated system prompt, please format your submission using the exact fields below.

Required Submission Fields

  • Provider: Name of the company or open-source org.
  • Model: Exact model name (e.g., v3.5, Opus, Pro).
  • Version/Date: When the prompt was active.
  • Verification: State if it is Verified (from official docs/APIs) or Observational (extracted via jailbreaks).
  • Source: Where or how this was discovered.
  • Context: The specific interface or tool it applies to.
  • Prompt Text: The raw text of the instructions.
  • Notes: Any anomalies or behavioral context.

To submit, please open a Pull Request on our GitHub repository with a new entry formatted using the JSON/HTML structure above.
